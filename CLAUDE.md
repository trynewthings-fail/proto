# proto

GitHub Pages demos for Try New Things, served at https://proto.trynewthings.studio.

- Each top-level folder is a standalone demo with its own `index.html`. Work only inside the folder you were asked about.
- The root `index.html` demo list is generated by `tools/build-index.py` (pre-commit hook and GitHub Action). Never edit it by hand.
- Folder-specific rules live in that folder's `CLAUDE.md`. Read it first, e.g. [`window-wall/CLAUDE.md`](window-wall/CLAUDE.md).
