# Import New Things

En Mac-app för att hämta in, titta igenom och sortera bilder – tänkt som ett enklare
alternativ till Capture One, byggd för att sedan skicka bilderna vidare till Photoshop.

## Ladda ner och installera

1. Gå till fliken **Actions** i det här projektet på GitHub.
2. Klicka på den senaste körningen av **"Import New Things – bygg Mac-appen"** (den med grön bock).
3. Längst ner under **Artifacts**: klicka på **Import-New-Things-mac** så laddas en zip-fil ner.
4. Dubbelklicka på zip-filen. Inuti ligger en till zip-fil – dubbelklicka på den också.
5. Dra **Import New Things** till mappen **Program**.

**Första gången du öppnar appen** säger Macen att den inte kan kontrollera utvecklaren.
Klicka **Klar**, öppna sedan **Systeminställningar → Integritet och säkerhet**, scrolla ner
och klicka **Öppna ändå** vid Import New Things. Det behövs bara en gång.

## Så använder du den (version 0.1)

- **Öppna mapp…** (⌘O) – välj en mapp eller ett minneskort. Undermappar tas med.
- **1–5** ger stjärnor, **0** tar bort dem.
- **← →** bläddrar. **G** växlar mellan stor bild och rutnät. **I** visar/döljer bildinformation.
- Filtret i verktygsfältet visar bara bilder med minst så många stjärnor.
- Stjärnorna sparas i en dold fil (`.importnewthings.json`) i mappen du öppnade.
